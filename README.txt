# DataWar

A structured, hands-on learning repository for **Data Engineering**. It covers the core technologies of the modern data stack — Snowflake, Databricks, PySpark, and Python — organized into a consistent, staged curriculum that takes you from fundamentals to production-scale projects.

## Overview

DataWar is built around a disciplined folder structure. Every technology follows the same four-stage pipeline — from curated resources, through guided practice, into end-to-end projects, and finally scenario-based case studies — so your learning stays organized, repeatable, and project-driven.

## Technologies

| Sequence | Stack          | Focus                                                        |
| -------- | -------------- | ------------------------------------------------------------ |
| 1        | **Snowflake**  | Data warehouse architecture, SQL, performance tuning, cost optimization |
| 2        | **Databricks** | Lakehouse platform, Delta Lake, notebooks, orchestration workflows |
| 3        | **PySpark**    | Distributed big-data processing, DataFrames, ETL pipelines    |
| 4        | **Python**     | Core programming for data engineering, scripting, automation  |

## Folder Structure

```text
DataWar/
├── 1_SnowFlake/
├── 2_DataBricks/
├── 3_Pyspark/
└── 4_Python/
```

Each technology folder follows the same internal layout, in order:

| Sequence | Folder        | Purpose                                                        |
| -------- | ------------- | -------------------------------------------------------------- |
| 1        | `1_Resource`  | Study material, links, notes, cheatsheets                       |
| 2        | `2_Practice`  | Hands-on exercises and small drills                            |
| 3        | `3_Projects`  | End-to-end real-world projects                                 |
| 4        | `4_SM`        | Sample / scenario-based case studies (Sample Material)         |

### Example — Snowflake Track

```text
1_SnowFlake/
├── 1_Resource/   → Cheatsheets, documentation links, learning notes
├── 2_Practice/   → Hands-on SQL drills and exercises
├── 3_Projects/   → Complete analysis & engineering projects
└── 4_SM/         → Scenario-based sample material
```

## Getting Started

The repository is self-contained as a learning workspace — clone it and start exploring:

```bash
git clone https://github.com/rahulsinghdatae-prog/DataWar.git
cd DataWar
```

Open the technology folder you want to study and progress through
`1_Resource` → `2_Practice` → `3_Projects` → `4_SM`.

## Purpose

Built as a personal, career-focused companion for advancing in Data Engineering. The structure mirrors how software and data teams actually organize work — so every skill learned translates directly into on-the-job capability.
